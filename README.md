# 📊 Zomato Performance Analysis Dashboard  

An interactive and visually appealing **Power BI dashboard** analyzing Zomato’s performance across multiple dimensions such as **sales trends**, **user demographics**, **city-wise performance**, and **customer behavior**. This project demonstrates expertise in **data modeling, visualization, and storytelling** using real-world scenarios.

---

## 🎯 **Objective**
To leverage Power BI for analyzing Zomato's **sales**, **ratings**, and **regional insights**, enabling **data-driven decision-making** and highlighting patterns that can improve business performance.

---

## ✅ **Key Features**
- **City-wise Sales Analysis:** Breakdown of revenue, order counts, and user engagement across top-performing cities.  
- **User Demographics:** Age and gender segmentation, including active, gained, and lost users.  
- **Revenue Insights:** Year-over-year sales growth with comparative KPIs and trend analysis.  
- **Customer Ratings & Preferences:** Insights into food preferences (Veg vs Non-Veg) and average ratings by region.    
- **Dynamic Filters**: Users can filter by top cities **Top N cities**, year, and performance metrics for custom analysis.
---

## 🛠 **Tools & Technologies**
- **Power BI** – Dashboard creation and data visualization  
- **Power Query** – Data cleaning and transformation  
- **DAX (Data Analysis Expressions)** – Custom measures for KPIs and time intelligence  
- **MS Excel / CSV** – Data source for analysis  

---

## 📈 **Insights Derived**
- Identified **top revenue-generating cities** and their order contribution  
- Highlighted **user churn** and **growth trends** across demographics  
- Detected **year-over-year performance fluctuations** and customer behavior patterns  
- Observed **food preference distribution** to target marketing strategies
